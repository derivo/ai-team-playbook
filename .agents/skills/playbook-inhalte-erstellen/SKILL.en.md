# Create new playbook content

[Deutsch (Standard)](SKILL.md) | English

The German `SKILL.md` is the executable, authoritative skill entry point.

Read [Documentation structure and maintenance](../../../docs/README.en.md) and the
[content template](../../../docs/vorlagen/inhalt.en.md). Links are relative to
this skill directory.

Check the catalog and existing documents for the same purpose. If the problem,
audience, or critical limits are missing, clarify them before dependent work.
Define the outline from the content template before writing prose. General
processes and standards belong in `docs/prozesse/` and stay independent of
tools and organizations; content for a named context is a use case in
`docs/anwendungsfaelle/` that links to its process.

Create exactly the requested content as a German and English language pair. The
German default keeps the file name without a suffix; English uses `.en.md`. Both
link to one another, carry the same substantive state, and begin as drafts.
Separate proposed rules from proven experience. Mark unknown ownership openly;
do not bind a team or person without a request. Name adaptation points without
creating speculative variants.

Link both versions from the appropriate language catalog. Check metadata,
internal links, Markdown, consistency between the versions, and claims against
their actual sources. Report files, results, and open points. Publication is a
separate task; a writing request does not authorize a commit.
